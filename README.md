# StutterSuite

StutterSuite は、話す場面で使う聴覚・リズム・原稿の手がかりを、ブラウザ内で調整する開発中のローカル優先ツールです。診断・治療を行うものではなく、効果を保証しません。

現在の主な機能は、DAF（2系統対応）、ホワイト／ピンク／ブラウンノイズのマスキング、直接／増幅フィードバック、メトロノーム、原稿の句分割とTTS、連続した斉読／TTS同期、プロファイル、補助なしを含む条件比較、振り返り、出力先選択、緊急停止、compact panel、JSONバックアップ／復元です。

FAF（再生速度を変えずに行うリアルタイム音程シフト）は未実装です。再生速度を音程シフトの代わりには使いません。

## 起動方法

Node.js を用意して、リポジトリのルートで次を実行します。

```bash
node server.js
```

ブラウザで `http://127.0.0.1:4174` を開いてください。

## プライバシーと安全

マイク音声と原稿は、このアプリから外部サーバーへ送信しません。TTSはブラウザがローカル音声として報告するvoice（`localService === true`）だけを利用します。ローカル音声が利用できない環境ではTTSを再生しません。設定や原稿、履歴はブラウザのローカル保存領域に保存されます。ヘッドホンを使い、最小音量から確認してください。緊急停止は補助音、マスキング、メトロノーム、TTSを停止し、マイクを解放します。通話アプリのミュートは別途操作が必要です。

ライセンスは未設定です。
