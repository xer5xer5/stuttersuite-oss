# StutterSuite

StutterSuiteは、通話や発表で使う音声・リズム・原稿の補助を、ブラウザ内で調整する開発中のツールです。音声は端末内で処理します。診断や治療を行うものではなく、効果を保証しません。

主な機能は、遅延・音程の調整（DAF・FAF、2系統対応）、ノイズ、自声モニター、メトロノーム、原稿の句分割と読み上げ（TTS）、斉読、設定の保存、補助なしを含む条件比較、振り返りの記録、出力先の選択、緊急停止、小型パネル、JSONバックアップ・復元です。

「通話・会議補助」はカスタム設定に統一しています。加工音声A・Bの追加遅延、音程、相対ゲイン、左右の出力を直接調整し、必要な機能だけ有効にしてください。既存のDAF・FAF設定も読み込めます。

FAFはブラウザ内のAudioWorkletで再生速度を変えずに音程を変更します。−12〜＋12半音、0.5半音刻み。音声を外部へ送ったり録音保存したりしません。HTTPSまたはlocalhostと対応ブラウザが必要です。

ホームの「使い方を確認する」から使用手順を確認できます。「使い方・仕組み」では、機能の操作、遅延と音程の違い、斉読やリズムの仕組み、研究結果と仮説、よくある質問、出典を紹介しています。ガイドの閲覧でマイクが起動することはありません。

## 起動方法

Node.js を用意して、リポジトリのルートで次を実行します。

```bash
node server.js
```

ブラウザで `http://127.0.0.1:4174` を開いてください。

## プライバシーと安全

マイク音声と原稿は、このアプリから外部サーバーへ送信しません。音声は処理中だけメモリで一時保持し、録音保存しません。補助停止でマイクを解放し、処理を終了します。TTSはブラウザがローカル音声として報告するvoice（`localService === true`）だけを利用します。ローカル音声が利用できない環境ではTTSを再生しません。設定や原稿、履歴はブラウザのローカル保存領域に保存されます。ヘッドホンを使い、最小音量から確認してください。緊急停止は補助音、マスキング、メトロノーム、TTSを停止し、マイクを解放します。通話アプリのミュートは別途操作が必要です。

## 開発・検証

Node.js 24で `npm test`。ブラウザ検証は最初に `npm ci` でテスト専用のElectron 44.5.1を取得し、`npm run test:browser` を実行します。画面を表示せず、音声出力とGPU利用を無効にし、実際の声を使わず合成入力で検証します。GitHub ActionsでもNodeテストとブラウザテストを実行します。Electronは本アプリの実行や公開には不要です。実装と検証の範囲は [WEB_IMPLEMENTATION_JA.md](WEB_IMPLEMENTATION_JA.md) を参照してください。

バックアップは2 MiBまで、原稿は50,000文字、設定は100件、句と履歴は各2,000件、メモは10,000文字までです。読み込みデータは検証・移行後に保存し、不正なデータや保存失敗で元データを置き換えません。保存データが壊れているか将来の形式だった場合は上書きを止め、元データの書き出し・正常なバックアップの復元・削除を案内します。保存容量不足時は未保存の内容もバックアップへ書き出せます。

緊急停止のショートカットは、このタブにフォーカスがあるときだけ有効です。別アプリを操作中のOS全体ショートカットはWeb版では提供しません。緊急停止ボタンまたはショートカットは、同じブラウザ・同じサイトの他タブへ停止を通知します。別のブラウザやプライベートウィンドウには伝わりません。タブを閉じるだけでは他タブは停止しません。

`vercel.json` にCSP（`frame-ancestors 'none'`）、X-Frame-Options、nosniff、Referrer-Policy、Permissions-Policyを設定しています。マイクと出力機器の選択は同じサイトで許可します。ローカルサーバーも同じヘッダーを使います。公開反映後は実際の応答ヘッダーも確認してください。

Vercelでは依存インストールをスキップし、テスト用Electronを取得しません。ローカル配信用server.jsとテスト・lockfileは静的配信から除外します。
